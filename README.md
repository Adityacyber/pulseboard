# 🚀 PulseBoard — Real-Time Polling Platform

PulseBoard is a modern real-time polling platform built with the MERN stack, Socket.IO, and Tailwind CSS.  
Users can create interactive polls, collect live responses, analyze results in real time, and publish results dynamically.

---

# ✨ Features

## 🔐 Authentication

- User Registration & Login
- JWT Authentication
- Protected Routes
- Persistent Login State
- Email Validation

---

## 📊 Poll System

- Create Multiple Choice Polls
- Multiple Questions Support
- Dynamic Options
- Required / Optional Questions
- Poll Expiry System
- Anonymous Response Toggle
- Prevent Duplicate Responses

---

## ⚡ Real-Time Features

- Live Analytics Updates using Socket.IO
- Real-Time Poll Result Publishing
- Auto Publish Results on Poll Expiry
- Live Dashboard Updates

---

## 📈 Analytics Dashboard

- Individual Poll Dashboard
- Total Responses
- Poll Status (Active / Expired / Published)
- Interactive Charts using Recharts
- Poll Question Analytics
- Public Results Sharing

---

## 🎨 Modern UI

- Premium Purple Theme
- Responsive Design
- Tailwind CSS
- Toast Notifications
- Glassmorphism UI

---
